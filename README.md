# EcoTravel 🌍

Basit ve kullanıcı dostu bir gezi uygulaması. EcoTravel, çevre dostu seyahat deneyimleri sunarak doğa ile uyum içinde keşif yapmanıza yardımcı olur.

## Özellikler

- 🔍 **Arama Fonksiyonu**: Destinasyonları kolayca arayın
- 🏷️ **Kategori Filtreleri**: Dağ, Sahil, Orman ve Şehir kategorilerine göre filtreleyin
- ⭐ **Değerlendirmeler**: Her destinasyon için kullanıcı puanları
- 🍃 **Çevre Dostu Puanı**: Destinasyonların ekolojik sürdürülebilirlik skorları
- 📱 **Responsive Tasarım**: Mobil, tablet ve masaüstü cihazlarda mükemmel görünüm
- 🎨 **Modern Arayüz**: Kullanıcı dostu ve şık tasarım

## Kullanım

1. `index.html` dosyasını bir web tarayıcısında açın
2. Ana sayfada Türkiye'nin popüler destinasyonlarını görün
3. Arama kutusunu kullanarak istediğiniz yeri bulun
4. Kategori butonlarına tıklayarak filtreleme yapın
5. Destinasyon kartlarında detaylı bilgilere göz atın

## Teknolojiler

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)
- Responsive Design

## Kurulum

Herhangi bir kurulum gerektirmez. Dosyaları indirin ve `index.html` dosyasını tarayıcınızda açın.

```bash
# Repoyu klonlayın
git clone https://github.com/yunusdemir2009/EcoTravel.git

# Dizine gidin
cd EcoTravel

# index.html dosyasını tarayıcınızda açın
```
